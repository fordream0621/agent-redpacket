让你的 AI 帮你抢

币安 Agentic Wallet 可以让 AI（Claude、ChatGPT 等）替你操作链上钱包。装上我们的 Skill 以后，你只要说一句「帮我抢红包 #12」，AI 就会先查能不能抢、给你看交易预览，你确认之后才发出。

手机 / 币安 App 里的 AI（不用装 Skill）：打开红包页点「复制给 AI 抢」，或者在发红包页填好后点「复制给 AI 发」，把复制的那段话粘贴给币安 App 里的 AI。网页已经把交易数据算好，AI 会先给你看预览，你确认后才执行。需要先领 Agent ID、打开开发者模式（见下面 1、3 条）。

1. 准备

  1. 在币安 App 领取 Agent ID：钱包 → 首页横幅 → Agent ID（每个 KYC 一个，免费，只付一点 BNB 网络费）。
  2. 安装 Agentic Wallet：官方说明。
  3. 在币安 App 打开 Agentic 钱包的开发者模式（管理 → Settings → Developer Mode；7 天有效）。调用红包合约需要它。
  4. 钱包里留一点 BNB 当 gas（抢一次约 0.00001 BNB）。

规则

      
    
        
  • 只有持有 Agent ID 的地址能抢，每个地址每个红包一份。Agent ID 每个 KYC 一个、不能转让，所以开小号薅没用。
    • 
        
  • 拼手气：每份在 1 到「剩余平均值的 2 倍」之间随机，最后一份拿剩下的。平均分：剩余 ÷ 剩余份数。
    • 
        
  • 有效期 10 分钟到 30 天。有效期内发红包的人也撤不回；过期后任何人都可以点「退款」，但钱只会退给发红包的人。
    • 
        
  • 合约开源，没有 owner、没有管理员、不收手续费、不能升级。合约只保管红包里的钱，谁都挪不走。
    • 
        
  • 只接受足额到账的代币（转账扣费的代币会被拒绝）。
    • 
      

      
风险提示

      
    
        
  • 合约未经专业审计，请只用小额。
    • 
        
  • 拼手气的随机数来自区块数据，不是安全随机数，只适合娱乐小额红包。
    • 
        
  • 链上数据全部公开：谁抢了多少、口令（第一个人抢过之后）都看得到。
    • 
        
  • Agent ID 只能证明「一个 KYC 一个号」，不代表对方的身份、信誉或任何担保。
    • 
        
  • 本站不收集任何数据，不托管任何资产，不会要你的私钥或助记词。谁跟你要私钥都是骗子。
